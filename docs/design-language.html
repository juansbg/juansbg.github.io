Design language  ·  v3 · September 2026
Four colours · Three faces · No corners

Omertà

A case file the narrator holds in the dark. Every screen is a page from the dossier: hard edges, hairline rules, one red for anything that draws blood, and type that does the theatre so the colour doesn't have to.

The four colours below are the whole palette. Everything else on this page, and everything in the app, is mixed from them with color-mix(). Nothing gets invented outside this set.

Vendetta
The red. Blood, the crew, the button that kills. A verb, never a decoration.
#FF0F0F
Midnight
The ground. Every night screen sits on this. Never pure black: the blue is what makes it feel like a room, not a void.
#000029
Ash
Cigar ash. Secondary ink, hairlines, the town's colour, anything muted.
#D8D4C0
Ledger
The paper the books are kept on. Primary ink at night; the one bright surface by day.

Exhibit A

Four rules everything answers to

The room is dark

One hand, one thumb, one voice reading aloud. Nothing flashes white. Nothing is smaller than 48px to hit. Contrast is a feature, not a compliance box.

Colour is evidence

Every colour on screen means something: whose side, who's dead, what's lethal. If a colour is only there to look nice, remove it. Red in particular is rationed.

Type does the theatre

Bebas Neue at poster size carries the mood, so the interface underneath can be plain, fast and legible. Personality lives in the headline, not in gradients.

The phone is a prop

It gets passed around a table. The reveal must not leak across the room, the bar must vanish while a player holds it, and a dead phone battery should not end the game.

Palette

Four base colours, each with a job. The derived scale below is how they stretch to cover surfaces, ink, lines and states without a fifth colour ever appearing.

Surfaces from Midnight

--groundMidnight. The page.
--surface91% Midnight + Ledger. Cards, the bar.
--surface-284% Midnight + Ledger. Sheets, menus.
--ground-day84% Midnight + Ash. The daytime page.
--paperLedger. Morning report, role card. The only bright surface.

Ink Ledger speaks, Ash annotates

--inkLedger. Titles, names, anything read aloud.
--ink-2Ash. Body copy, hints, secondary labels.
--ink-mute62% Ash + Midnight. Timestamps, eyebrows.
--ink-faint36% Ash + Midnight. Disabled, the dead.
--hairline22% Ash. Every rule and border.

Vendetta states the only colour with states

--vendettaFull. Lethal buttons, crew marks, the dead in the report.
--vendetta-dim55% + Midnight. Strike-throughs, blocked kills.
--vendetta-glow38% + transparent. The crew's night glow.

Who gets which colour

  • Crew is Vendetta. Their seats glow red for the narrator at night, their marks in the log are solid red squares.
  • Town is Ash. Civilians, paper people. Solid Ash squares in the log, plain Ash hairline seats in the circle.
  • The two occult roles are hollow. An Ash outline on Midnight instead of a fill. Same palette, visibly other.
  • The dead are faint. Ink drops to --ink-faint with a single Vendetta-dim strike across the seat. Never removed, never hidden.
  • The narrator's hand is Ledger. Whatever is selected, focused or primary goes Ledger-on-Midnight, inverted. It reads as "you are here" without needing a third colour.

Exhibit C

Typography

Three faces, each with one job. Bebas Neue is the right call for titles: it's a condensed poster caps face, it sets tight, and with no rounded terminals it agrees with the corners. It has no lowercase, which is exactly why it needs a workhorse next to it.

Display · Bebas NeueTitles, buttons, seats
Night three
The table
Case closed

Always caps, tracked 0.02–0.05em, line-height 0.9. Never below 1.25rem: it gets spidery. Never for a sentence that has to be read aloud.

Body · IBM Plex SansAnything read aloud
The Fixer moved to protect Marta. The crew came for her anyway. Nobody died last night.

Weights 400 / 500 / 600 only. Plex has a typewriter ancestry without being a costume, and its Spanish diacritics are clean at small sizes. Body 1rem/1.55, ~62 characters wide.

Data · IBM Plex MonoNumbers, log, hex
N3 02:14 KILLER → seat 07 N3 02:15 GUARD → seat 07 N3 02:16 blocked

Seat numbers, night counters, timestamps, the timeline. Always tabular-nums. Weights 400 / 500. It's the dossier's typewriter, and it shares Plex Sans' skeleton so the two never argue.

Rules

  • Every button label is Bebas. It's what makes a 48px target look like a target and not a link.
  • Every sentence the narrator reads is Plex Sans. The night script, the morning report, the outcome text. Never caps.
  • Every number is Plex Mono. Even inside a sentence: seat 07 sits in Mono while the words around it stay Sans.
  • No italics. Emphasis is weight 600 or Ledger-on-Ash, never a slant. It keeps the page looking typed, not typeset.
  • Self-host all three. The PWA rule bans CDNs. Use @fontsource/bebas-neue, @fontsource/ibm-plex-sans and @fontsource/ibm-plex-mono, latin subsets, six woff2 files, roughly 160 KB. Vite bundles them and the service worker caches them.
  • If you ever want lowercase in titles, the swap is Big Shoulders Display, a Chicago-built condensed grotesque with nine weights. Same silhouette, more range. Bebas first though; it's the stronger voice.
Exhibit D

Shape & surface

Radius is zero. Everywhere. Buttons, seats, cards, sheets, focus rings, the menu. A single rounded corner would give the game away as a generic app; the hard edge is what makes it a document.

  • Lines, not shadows. Depth comes from a 1px Ash hairline and a step up the surface scale. Drop shadows are reserved for the menu sheet and the reveal card, the two things that physically sit on top.
  • One ornament: register marks. The little L-shaped ticks in opposite corners of a file card. They say "this is a page in the file". Use them on cards that represent a record, not on buttons or seats.
  • Hairline grids. Groups of equal things (principles, phase tiles, the list layout) sit in a 1px grid with the gap painted in --hairline, like ruled paper.
  • The stamp. A rotated, outlined Vendetta word at 2px stroke. Used once per screen at most: CASE CLOSED on the end-of-game report, BLOCKED across a failed kill. Never on a button.
  • The redaction bar. A solid Midnight block where a word would be. It's the visual for "you can't see this yet", used in the reveal handoff and the picker for "show a role again".
  • Seats are squares. Not circles. The seating circle is still a ring of positions, but each seat is a square tile, kept upright so the name reads at any position. Square tiles in a ring look like chairs around a table; circles look like avatars.

Do

  • Paint the gap in a grid, not a border on each cell
  • Use --surface steps for depth
  • Let the Bebas title be the biggest thing on screen
  • Leave Midnight ground visible around cards

Don't

  • Any border-radius above 0, including pills
  • Gradients, blur, glass, glow on anything but the crew
  • Icons where a Bebas word fits
  • A fifth colour, however "neutral"

Exhibit F

Night and day

Night

Ground is Midnight. Ink is Ledger. The crew glows. This is the default state of everything.

html[data-phase="night"]

Day

Ground warms to 84% Midnight + Ash. Still dark, still the same ink, but the blue drains out. The report card is the sunrise.

html[data-phase="day"]
  • The page never goes light. Day is a warmer dark, not a white theme. The dark-room constraint holds in both phases; the room's own lights are what change.
  • Dawn is a 600ms crossfade of the ground colour, the slowest transition in the app. Everything else cuts.
  • The report is the only bright thing by day, and it scrolls inside its own region so the ground stays visible around it.
  • Setup and reveal are "night". No phase attribute means Midnight.
Exhibit G

Motion

Film cuts, not app fades. A dossier page is turned, not dissolved. The existing durations stay; what changes is what each one is for.

Instant · 90ms
Press

Button press, seat select. A 1px downward nudge and a colour swap. Nothing eases.

Fast · 150ms
Cut

Screen to screen. A hard vertical wipe with --ease-out, like sliding the next page over. No cross-dissolve.

Base · 220ms
Slide

The reveal card, the menu sheet, the timeline sheet. Things that physically sit on top slide up from the bottom edge.

Slow · 600ms
Dawn

Only the ground colour at phase change. The single deliberately slow moment, so the room notices morning.

Ambient · 2.6s
Breathe

The crew glow at night, for the narrator's eyes only. The only looping animation in the app. Frozen at mid-glow under prefers-reduced-motion.

Never
Bounce

Drop --ease-spring. Overshoot reads as playful; this game isn't.

Exhibit H

Voice

Labels are stamps. Sentences are testimony. The app speaks like a case file: terse in caps, plain in prose, never a joke.

  • Bebas labels are two or three words. NIGHT 3. THE TABLE. MORNING REPORT. CASE CLOSED. Long enough to be a title, short enough to be a stamp.
  • Buttons name the consequence. "Confirm the hit", not "OK". "Begin the night", not "Next".
  • Questions to the narrator are questions. "Who does the crew kill?" as a Bebas lg title over the circle.
  • Outcome sentences are past tense, active, one clause. "The crew killed Pau." Both languages get the same length and weight.
  • No exclamation marks anywhere.

Exhibit I

tokens.css, proposed

Drop-in replacement for the :root block in src/ui/tokens.css. The spacing, touch and duration tokens are unchanged; the radii collapse to zero; the palette, faces and role accents are new. Existing rules that reference --accent, --town, --crew and --role-* keep working through the aliases at the bottom.

src/ui/tokens.css
/* The single design-token set for the app. Nothing outside this file
   may invent a colour, a face or a radius. */

:root {
  color-scheme: dark;

  /* The four. Every other colour is mixed from these. */
  --vendetta: #FF0F0F;   /* blood, the crew, anything lethal */
  --midnight: #000029;   /* the ground */
  --ash:      #D8D4C0;   /* secondary ink, hairlines, the town */
  --ledger:   #F7F6F2;   /* primary ink; the one bright surface */

  /* Surfaces */
  --bg:             var(--midnight);
  --bg-day:         color-mix(in oklab, var(--midnight) 84%, var(--ash));
  --surface:        color-mix(in oklab, var(--midnight) 91%, var(--ledger));
  --surface-raised: color-mix(in oklab, var(--midnight) 84%, var(--ledger));
  --surface-sunken: color-mix(in oklab, var(--midnight) 96%, var(--ledger));
  --paper:          var(--ledger);
  --on-paper:       var(--midnight);

  /* Ink */
  --fg:       var(--ledger);
  --fg-2:     var(--ash);
  --fg-muted: color-mix(in oklab, var(--ash) 62%, var(--midnight));
  --fg-faint: color-mix(in oklab, var(--ash) 36%, var(--midnight));

  /* Lines */
  --hairline:        color-mix(in oklab, var(--ash) 22%, transparent);
  --hairline-strong: color-mix(in oklab, var(--ash) 48%, transparent);

  /* Vendetta states: the only colour with states */
  --lethal:      var(--vendetta);
  --on-lethal:   var(--midnight);           /* never white on red */
  --lethal-dim:  color-mix(in oklab, var(--vendetta) 55%, var(--midnight));
  --lethal-glow: color-mix(in oklab, var(--vendetta) 38%, transparent);

  /* Teams and states */
  --town:   var(--ash);
  --crew:   var(--vendetta);
  --occult: transparent;                    /* hollow: 1px --ash outline */
  --dead:   var(--fg-faint);

  /* Primary action is the narrator signing the page. */
  --accent:    var(--ledger);
  --on-accent: var(--midnight);
  --danger:    var(--vendetta);
  --ok:        var(--ash);

  /* Faces. Self-hosted via @fontsource; the PWA rule bans CDNs. */
  --font-display: 'Bebas Neue', 'Oswald', Impact, 'Arial Narrow', sans-serif;
  --font-body:    'IBM Plex Sans', system-ui, -apple-system, 'Segoe UI', sans-serif;
  --font-mono:    'IBM Plex Mono', ui-monospace, Menlo, Consolas, monospace;
  --track-display: 0.03em;
  --track-label:   0.12em;

  /* Type scale: display steps are Bebas, text steps are Plex. */
  --text-xs:   clamp(0.75rem, 3vw, 0.875rem);
  --text-sm:   clamp(0.875rem, 3.5vw, 1rem);
  --text-md:   clamp(1rem, 4.2vw, 1.2rem);
  --text-lg:   clamp(1.5rem, 5.5vw, 2rem);
  --text-xl:   clamp(2.25rem, 8vw, 3.5rem);
  --text-hero: clamp(3.5rem, 14vw, 7rem);

  --space-1: 0.25rem;  --space-2: 0.5rem;  --space-3: 0.75rem;
  --space-4: 1rem;     --space-5: 1.5rem;  --space-6: 2rem;  --space-7: 3rem;

  /* Shape: there are no corners. */
  --radius-sm: 0;  --radius-md: 0;  --radius-lg: 0;  --radius-pill: 0;
  --mark: 10px;                             /* register-mark tick length */

  --touch: 48px;

  /* Motion: cuts, not fades. */
  --dur-instant: 90ms;
  --dur-fast:    150ms;
  --dur-base:    220ms;
  --dur-slow:    600ms;                     /* dawn only */
  --ease-out:    cubic-bezier(0.16, 1, 0.3, 1);
  --ease-in-out: cubic-bezier(0.65, 0, 0.35, 1);
  /* --ease-spring removed: nothing here bounces. */

  --shadow-lift: 0 6px 24px rgb(0 0 0 / 0.55);   /* menu sheet only */
  --shadow-deep: 0 18px 48px rgb(0 0 0 / 0.7);   /* reveal card only */
}

/* Role accents collapse to team + kind. outcomeAccent() keys on these
   three instead of nineteen hues; the two-letter mark carries identity. */
:root {
  --role-crew:   var(--crew);
  --role-town:   var(--town);
  --role-occult: var(--ash);   /* as an outline, not a fill */
}

html[data-phase="day"] { --bg: var(--bg-day); }

@media (prefers-reduced-motion: reduce) {
  :root { --dur-instant: 1ms; --dur-fast: 1ms; --dur-base: 1ms; --dur-slow: 1ms; }
}
